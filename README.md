# Funnyfy_IPP

🎨 Funnyfy
Transform any photo into Gautam Adani using advanced particle physics and image processing! This is a fun educational project for Image Processing (IPP) coursework, inspired by Spu7Nix.

🌐 Live Demo: https://funnyfyipp.netlify.app

✨ Features
- Photo Upload - Upload images in PNG, JPG, or WEBP format
- Live Camera Capture - Take photos directly from your webcam with countdown and instant capture options
- Multiple Transformation Algorithms:
- Swarm Vortex (Spu7Nix Particle Physics)
- Pixel Sorter (Obamify)
- Liquid Flow (Fluid Dynamics)
- Cybernetic Glitch
- Customizable Settings:
- Grid resolution (32×32 to 80×80 tiles)
- Color style (Pure or Hybrid Chromatic Morph)
- Particle shapes (Rounded, Square, Orbs, Diamonds)
- Real-time Playback Control - Scrub through the transformation, adjust speed (0.5x, 1.0x, 2.0x), reverse, or reset
- Performance Monitoring - Live FPS and particle count display
- Multiple Target Portraits - Choose between different Gautam Adani images

📚 How It Works
- Load Input - Upload a photo or capture from webcam
- Select Algorithm - Choose your preferred transformation physics
- Customize - Adjust grid resolution, colors, and particle shapes
- Transform - Click "Funnyfy Now" to animate the transformation
- Scrub & Play - Use the timeline to scrub through the animation or reverse it

The algorithm works by:
- Dividing the input image into a grid of particles/tiles
- Calculating displacement vectors from the input to the target Gautam Adani portrait
- Animating particles using physics simulations to morph between images

🎓 Educational Purpose - This project was created for the Image Processing (IPP) coursework to demonstrate:
- Image sampling and pixel manipulation
- Grid-based image decomposition
- Real-time canvas rendering with WebGL
- UI/UX design for interactive tools
